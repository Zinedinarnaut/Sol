Sol 0.1.0 is the first public developer preview of the native macOS frontend
and its packaged Sol Engine integration.

## Highlights

- Native AppKit and SwiftUI library, setup, settings, profiles, and session UI
- AppKit-owned game surface presented through Vulkan and MoltenVK
- Bundled, UI-free Sol Engine runtime based on a pinned Ryubing revision
- Native keyboard and controller assignment with per-player remapping
- Keys, firmware, DLC, title-update, and content-folder management
- Native launch progress, playtime tracking, fullscreen, and session controls
- Experimental DLSM Spatial, Temporal, and frame-generation research code

## DLSM status

DLSM remains experimental. It is disabled in normal public-preview launches.
Spatial is currently the strongest development mode; Temporal and frame
generation still need broader GPU-bound testing and latency work.

## Installation

This release is source-only. Follow the build instructions in the
[README](https://github.com/Zinedinarnaut/Sol#build-from-source). A precompiled
download will be added only after Sol can be distributed with Developer ID
signing and Apple notarization.

Sol does not include games, keys, firmware, or other console system files.

## Known limitations

- This is an early preview, not a compatibility guarantee for every title.
- Apple account and iCloud features require a correctly provisioned local build.
- Temporal reconstruction and frame generation are not ready for normal use.
- Some controller, multiplayer, and repeated-session paths still need wider
  hardware testing.
