Sol 0.1.1 corrects the first public source preview by including the complete
patched Sol Engine source directly in the repository.

## What changed

- Every clone and GitHub source archive now contains the engine core used by
  Sol, pinned to upstream commit `a82350bb774f70fcbd41c9987bf67a3775409963`.
- Sol's runtime, stability, native-surface, multiplayer, and DLSM changes are
  applied in the checked-in source and remain available as reviewable patches.
- Builds verify the bundled source instead of cloning an external repository.
- Generated engine artifacts, games, keys, firmware, and signing material
  remain excluded.

This remains a source-only developer preview. A notarized application download
will follow when Developer ID distribution signing is available.
