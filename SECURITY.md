# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose local
files, account data, multiplayer credentials, or execute untrusted content.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the maintainers through their GitHub profiles and
ask for a private reporting channel before sharing details.

Include the affected revision, macOS version, impact, and the smallest safe
reproduction you can provide. Do not send games, firmware, keys, save data,
Apple credentials, or other protected content.

Only the latest source revision is supported during the developer preview.
